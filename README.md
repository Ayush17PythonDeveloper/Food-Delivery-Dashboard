# Food Delivery Analytics Dashboard

1. A professional interactive dashboard designed to analyze food delivery orders and business performance.
2. Analyzes total orders, revenue, restaurant performance, cuisine categories, delivery time, and customer ratings.
3. Uses Python for data cleaning, processing, and analytics.
4. Uses SQL for database management, data storage, and analytical queries.
5. Uses Microsoft Power BI and Excel to create interactive dashboards, reports, and business insights.
